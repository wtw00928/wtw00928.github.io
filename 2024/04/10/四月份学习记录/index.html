    局部变量与成员变量有什么区别？

    • 局部变量不会自动赋值，成员变量会自动赋值（局部变量在声明时必须显式地赋值，否则编译器会报错）

    • 局部变量存储在栈内存中，成员变量存储在堆内存中
    • 生存时间不同

  4. 重载方法与重写方法的区别

    重载方法 重写方法
    方法名 相同 相同
    发生时期 类中 子类继承父类
    参数类型 不同 相同
    返回类型 可以不同 范围要比原来的小或相等
    异常 可以不同 范围要比原来的小或相等
    访问修饰符 可以不同 不能对private、static、final方法进行重写，一定不能做更严格的限制（可以降低限制）
    两同两小一大

Java

  • 数组array可以存储对象，只要将一个数组声明为对象数组。

  • 在Java的集合里比如ArrayList，LinkedList等都会说线程不安全，不同步的状况。
    这里的不同步指的是。当使用线程和web的时候，对这个集合对象进行操作，那么不同的线程，和不同的web客户端所获取的这个集合对象是不同的。所以是说不同步，且不安全的。

    比如说现在A线程 和B线程，要拿到这个集合对象，现在集合对象里有 [1,2,3]。那么A在集合对象里添加了一些数字[1,2,3,4,5]。那么这个时候B线程取拿这个集合对象的时候，还是[1,2,3]而不是A已经修改过的集合[1,2,3,4,5]。所以说这里的集合不同步。

  • //选择排序
//选择出为排序数组中最小的一个
void selectSort(nums[]){
    for(int i = 0; i < nums.length - 1; i++){
        int k = i;
        //找到未排序的最小元素的索引
        for(int j = i + 1; j < nums.length; j++){
            if(nums[j] < nums[k]){
                k = j;
            }
        }
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
//插入排序
//左边一直是排序好的，右边不断扩张
void insertSort(nums[]){
    for(int i = 1; i < nums.length; i++){
        int base = nums[i], j = i - 1;
        while(j>=0 && nums[j] > base){
            nums[j + 1] =  nums[j];
            j--;
        }
        nums[j+1] = base;
    }  
}
//////快速排序
void swap(int nums[], int i, int j){
    int temp = nums[i];
    nums[i] = nums[j];
    nums[j] = temp;
}
//哨兵划分
int partition(int nums[], int left, int right){
    int i = left, j = right;
    while(i<j){
        while(i < j && nums[j] >= nums[left]){
            j--;
        }
        while(i < j && nums[i] <= nums[right]){
            i++;
        }
        swap(nums,i,j);
    }
    swap(nums,i,left);
    return i;//返回基准数
}
void quickSort(int nums[], int left, int right){
    if(left >= right){
        return;
    }
    int i = partition(nums,left,right);
    quickSort(nums,left,i-1);
    quickSort(nums,i+1,right);
}


  • //第77题
//当向结果列表 res 添加路径时，应该添加路径的一个副本而不是直接添加当前路径。
//这是因为 Java 中的集合是通过引用传递的，因此如果直接将 path 添加到 res 中，
//后续的修改将影响到已经添加到 res 中的路径。
class Solution {
    List<Integer> path = new ArrayList<>();
    List<List<Integer>> res = new ArrayList<>();

    public List<List<Integer>> combine(int n, int k) {
        backtracking(n,k,1);
        return res;
    }

    public void backtracking(int n, int k, int start){
        if(path.size() == k){
            res.add(new ArrayList<>(path));
            return;
        }
        for(int i = start; i <= n; i++){
            path.add(i);
            backtracking(n,k,i+1);
            path.remove(path.size() - 1);
        }
    }
}
